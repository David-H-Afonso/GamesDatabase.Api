# Imágenes del README

[English](SCREENSHOTS.md) · [README API](../README.es.md)

Las imágenes muestran el **cliente web real de Games Database usando esta API**, no
un panel administrativo de la API. Comparten la demo aislada del Front con 24 juegos
de catálogo Steam público: imágenes/datos reales y organización ilustrativa, sin jugador
vinculado, logros, tiempo, notas o fechas de partida inventados. No usan datos privados.

Inglés/español son ajustes reales de la app compilada. Se ha codificado a WebP sin
componer ni reemplazar interfaz. La revisión de metadatos es una respuesta real del
proveedor y abrir la guía no crea juegos de ejemplo.

Lista completa de juegos/App IDs, fuentes públicas, titularidad de imágenes y límites:
[notas de capturas del Front](https://github.com/David-H-Afonso/GamesDatabase.Front/blob/HEAD/docs/SCREENSHOTS.es.md).
La licencia de aplicación no relicencia imágenes de juegos. Las capturas son del código
actual, no otra release, prueba de dispositivo físico ni certificación de hosting.
