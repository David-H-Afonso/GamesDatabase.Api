# README images

[Español](SCREENSHOTS.es.md) · [API README](../README.md)

The README images show the actual **Games Database web client using this API**, not
an API administration dashboard. They share the Front's isolated 24-game public Steam
catalog demo: real artwork/catalog metadata, illustrative organization, no linked player,
invented unlocks, playtime, grades or play dates. No personal or private test data is used.

The English/Spanish images are real language settings in the compiled application.
They were encoded to WebP without compositing or replacing UI content. The metadata
review is a real provider response and the guide creates no game samples by opening it.

The full game/App ID list, public sources, third-party-artwork ownership and capture
limitations are in the [Front screenshot notes](https://github.com/David-H-Afonso/GamesDatabase.Front/blob/HEAD/docs/SCREENSHOTS.md).
The application license does not relicense game artwork. Captures reflect the current
source, not another published release, physical-device test or hosting certification.
